(2024)DirectX 11 2.5D Platformer

This project features a custom object loader, scene setup through configuration file parsing, and custom HLSL shaders. It includes both per-pixel and per-vertex shading to compare visual quality and performance. The only external libraries used were DirectXMath and IMGUI.

I developed this game using C++ and DirectX 11 as the final project for my C++ Programming and Design, and Real-Time Graphics courses during the first trimester of my master’s studies.

(2024-2025)Multiplayer VR Croquet Game

This is a VR croquet game, playable by up to 8 players online, developed using the Unity XRI template for VR and Unity Cloud for networking. Azure DevOps was used for agile project management and GitHub for version control.

As part of a four-member team, I worked on this game as Scrum Master, Project Manager, and Unity/C# Developer for my Commercial Development Practice course during the first two trimesters of my master’s studies.
